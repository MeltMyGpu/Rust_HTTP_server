# Rust HTTP server 11/01/25 notes / planning

## HttpRequest struct 
I need to create a struct to hold and handle HTTP requests. This struct will be 
created by the server and handed to an endpoint controller that will locate the 
appropriate endpoint and call its service.

### What it needs to do:
__Hold the TcpStream__
This will avoid the problem of the stream going out of scope before I'm done with it, 
along with avoiding having to pass the stream between functions, or keep returning it.

This may turn out to be unnecessary, currently I don't actually remember enough about 
how TCP connections/streams work to say for sure.

## Endpoints and their services 
An Endpoint struct will have to store data relevant to the endpoint such as:
- It's request type (get, post, etc)
- It's URI
- It's service
